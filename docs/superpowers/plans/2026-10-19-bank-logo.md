# Logo Bank Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin mengunggah logo per bank. Logo dicari lewat `bankId` setiap kali dibaca dan tampil di semua tempat yang sudah punya gambar bank, dengan fallback kotak kode.

**Architecture:** Logo disimpan sekali di `banks.doc.logo = { path, url }`: file di bucket publik `bank-logos` (Supabase) atau data URL (mock). `mockApi.js` punya `bankFor(db, { bankId, bankName })` yang dipakai di `productsOf`, snapshot (`banks` + `mortgage.bank`), dan `simulationSource`. Saat simpan, `bankId` diisi dari nama yang dipilih. UI memakai `BankMark({ bank })` dengan `<img>` dan fallback kode saat `onError`.

**Tech Stack:** React 19 + Vite, Vitest (jsdom), Playwright (mock), Postgres 17 + Supabase Storage, pgTAP lewat `/pg/query`.

**Spec:** `docs/superpowers/specs/2026-10-19-bank-logo-design.md`

## Global Constraints
- Bucket `bank-logos`: `public = true`, `file_size_limit = 1048576`, `allowed_mime_types = {image/jpeg,image/png}`. Tulis/hapus hanya `super_admin`.
- `LOGO_UPLOAD = { maxFileMb: 1, formats: ['jpg', 'png'] }`.
- Logo tidak pernah disalin ke produk, pengajuan, KPR, atau simulasi. Yang disalin hanya `bankId`.
- `bankName` tetap disimpan dan dipakai untuk teks, email, dan audit. Fungsi email/reminder tidak disentuh.
- UI hanya lewat `src/data/api.js`. Visual mengikuti token yang ada (`ring-border`, `bg-white`, radius `BankMark` yang sudah ada).
- Pekerjaan sesi lain yang belum di-commit (`reminder_email_retry`, `supabase/README.md`, spec 2026-10-09, tes 004/005) tidak boleh ikut di-stage.

## Review Focus
- URL logo mati (file lama dihapus, tab masih terbuka) → kotak kode, bukan ikon rusak (Task 4, tes `BankMark`).
- Admin mengunggah ulang file dengan nama sama → path baru, tersimpan tanpa "Tidak ada perubahan" (Task 1).
- Bank diganti namanya setelah KPR disimpan → logo KPR tetap ketemu lewat `bankId` (Task 1).
- Bank nonaktif → tetap ada di `snap.banks` (dropdown), produknya tetap keluar dari pencocokan (Task 1).
- Simpan gagal setelah file terunggah (versi konflik) → file baru dihapus dari Storage (Task 2).

```js
// Bank code shown in place of a logo for a bank outside the admin list (spec 2026-10-19).
export const markOf = (name) => String(name ?? '').replace(/^Bank\s+/i, '').slice(0, 3).toUpperCase()
// The admin's banks (snapshot `banks`), then "Bank lainnya" for any other bank.
export const bankOptions = (banks = []) => [...banks.map((b) => ({ value: b.name, label: b.name })), { value: 'Bank lainnya', label: 'Bank lainnya' }]
// What a saved record shows in that dropdown: its bank's current name, else its saved name when listed, else "Bank lainnya".
export function bankChoice(banks = [], { bankId, bankName } = {}) {
  if (!bankId && !bankName) return ''
  return (banks.find((b) => b.id === bankId) ?? banks.find((b) => b.name === bankName))?.name ?? 'Bank lainnya'
}
```

```js
// The demo has no Storage: a chosen logo file is kept as a data URL under a fresh name (spec 2026-10-19 §3).
const withLogo = (write) => async (...args) => {
  const input = args.at(-1)
  const file = input?.values?.logo
  if (!(file instanceof Blob)) return write(...args)
  const problem = uploadProblem(file, LOGO_UPLOAD)
  if (problem) fail(problem.code, problem.message, problem.status)
  const url = await new Promise((resolve, reject) => {

    reader.onerror = () => reject(reader.error)
```

`index.js` (import `LOGO_UPLOAD`, `LOGOS_BUCKET`, `publicUrl`):

```js
// Logo to Storage first, then the bank; a failed save takes the new file out, a successful one the file it replaced.
async function saveBankLogo(values, previous, write) {
  const file = values?.logo instanceof Blob ? values.logo : null
  let path = null
  if (file) {
    const problem = uploadProblem(file, LOGO_UPLOAD)
    if (problem) throw new ApiError({ code: problem.code, message: problem.message }, { status: problem.status })
    path = filePath([], file)
    await uploadFile(LOGOS_BUCKET, path, file)
  }
  let bank
  try {
    bank = await write(file ? { ...values, logo: { path, url: publicUrl(LOGOS_BUCKET, path) } } : values)
  } catch (e) {
    await removeFiles(LOGOS_BUCKET, [path])
    throw e
  }
  if (values?.logo !== undefined && previous !== path) await removeFiles(LOGOS_BUCKET, [previous])
  return bank
}
```

```sql
-- Bank logos (spec 2026-10-19): a public bucket only the super admin writes; every signed-in user reads every bank,
-- since a KPR may sit at a bank that left matching; records saved before bankId get it when their bank name matches.

insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types) values
  ('bank-logos', 'bank-logos', true, 1048576, array['image/jpeg', 'image/png'])
on conflict (id) do update set public = true, file_size_limit = excluded.file_size_limit, allowed_mime_types = excluded.allowed_mime_types;

-- {uuid}.{ext}; reading goes through the public URL. remove() needs select as well as delete.
create policy bank_logos_insert on storage.objects for insert to authenticated with check (
  bucket_id = 'bank-logos' and (select private.has_role('super_admin')));
create policy bank_logos_select on storage.objects for select to authenticated using (
  bucket_id = 'bank-logos' and (select private.has_role('super_admin')));
```

```jsx
// A bank's logo when it has one that loads; otherwise its code (spec 2026-10-19 §4). `failed` holds the URL that broke,
// so a new logo is tried again.
export function BankMark({ bank, size = 'md', tone = 'primary' }) {
  const [failed, setFailed] = useState(null)
  const logo = bank?.logoUrl && bank.logoUrl !== failed ? bank.logoUrl : null
  return (
    <span
      className={cn(
        'flex shrink-0 items-center justify-center overflow-hidden font-extrabold italic',
        size === 'lg' ? 'size-14 rounded-2xl text-base' : size === 'sm' ? 'size-10 rounded-lg text-[13px]' : 'size-[52px] rounded-xl text-[15px]',
        logo ? 'bg-white p-1.5 ring-1 ring-border' : tone === 'primary' ? 'bg-secondary text-primary' : tone === 'glass' ? 'bg-white/15 text-white' : 'bg-muted text-ink-3',
      )}
      aria-hidden
    >
      {logo ? <img src={logo} alt="" className="size-full object-contain" onError={() => setFailed(logo)} /> : bank?.mark}
    </span>
  )
}
```
